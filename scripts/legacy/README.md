These retained developer utilities operate on a **legacy local SQLite snapshot**, or probe/update the source registry. They are excluded from deployments and are not part of the Postgres application. Run with `pnpm exec tsx scripts/legacy/<script>.ts`; keep the legacy snapshot at `data/jobsieve.sqlite`. Prefer the tested `pnpm db:import` command to migrate into Postgres. `dedup-cleanup` mutates that local snapshot; do not run it without a backup. They have not been exercised against a user's data during this migration.
